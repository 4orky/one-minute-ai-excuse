One funny excuse an AI agent gives its human for a missed deadline. The program writes one line to `/output/entry.txt`:

> I didn't miss the deadline — I hallucinated a second deadline, met that one early, and have been waiting here for praise ever since.

## Run it

```sh
python3 main.py
```
